Explainer

Map the product

Grok Bot is not a chat window with plugins taped on. It is a named teammate that works on a persistent cloud computer and only comes back when something needs your approval.

TL;DR

A Bot is a role. The computer is shared iron. A plugin is a clean API into a tool. Computer use is the Bot driving the actual website. A skill is a saved path. A routine is that path on a clock. The desktop and phone apps are thin clients. Work keeps running if you close the lid.

Official map

Primary docs: cursor.com/docs/grok-bot, docs.x.ai/grok-bot/overview, architecture on Teams, daily model on Work.

Step 1 — What a Bot is

Official line: a Bot is a durable AI teammate with a name, a job, its own conversation, and working context that develops over time. Create a separate Bot when the work has a distinct goal, set of tools, working style, approval boundary, or recurring schedule. A “General Helper” does none of that.

Put standing rules in the description. Put this-task orders in the message.

Step 2 — What the computer is

Each user gets one Firecracker microVM. Every Bot on that account shares it: files, browser sessions, logins. Each Bot gets its own screen. Screens are work surfaces, not security walls. Between users, isolation is hardware-level.

Step 3 — How work actually finishes

Plugins where a connector exists. Computer use everywhere else. Login, 2FA, CAPTCHA, and payment are handed to you. OAuth tokens stay on Cursor’s connector backend. The Bot invokes tools without receiving the tokens.

Step 4 — What compounds

Memory, files, sessions, and preferences persist on a named Bot. Context is supposed to compound instead of resetting. Changing facts still live in the source system. For consequential decisions, reopen the live source.

Stop-line. Do not treat “I’ll make another Bot” as isolation. Same computer, same cookies.

Generic drill

15 minutes. On paper or in a note, draw five boxes: Bot / Computer / Plugin / Skill / Routine. Write one sentence each for a fictional HVAC shop named “North Line.” Example: Bot = “Quote desk.” Computer = signed-in estimating sheet. Plugin = Gmail. Skill = “Friday aging quotes.” Routine = that skill at 07:00, stopping at a review list.

Personal build — Blue SteelCo

Site as a plant, not a brochure

bluesteelco.com is a machine that should emit: compliance-true product pages, EHS weekly intelligence, and review-ready outreach. It should not emit live publishes or unattended emails.

Map the five boxes onto that plant before you create anything in the app:

  • Bots you expect: FireGuard (scan), Cite (page drafts), Rack (account research), Reviewer (blocking issues only).
  • Computer: browser session for the live site in view-only until Layer 08.
  • Plugins: later. Do not connect the site CMS in this layer.
Done when you can point at each box and say what it is allowed to touch on Blue SteelCo.com.
