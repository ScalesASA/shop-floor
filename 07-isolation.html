Explainer

Isolation and teams

The security model is four bolts: per-user isolation, no access by default, human approval gates (Auto Review), administrative control. Inside one user, Bots isolate personality, not compute.

TL;DR

One Firecracker microVM per user. Need a separate credential set? You need a separate Cursor user. Team Rules are short standing bans. Auto Review instructions are the allow/block list for the independent reviewer. Network Controls and action recording are Enterprise.

Step 1 — Know which wall you are standing on

User-to-user: hardware isolation. Bot-to-Bot: none for files and cookies. Plugin tokens: held by Cursor, not printed to the model. Local execution on your laptop: per-command approval by default, can be turned off.

Step 2 — When an SMB should split accounts

Split if one workload must hold production CMS, payroll, or banking and another workload is allowed to roam the public web. Do not split because the names are different. Names are cheap. MicroVMs are the wall.

Step 3 — Team extras if you grow a seat

Team Rules scoped to Grok Bot. Cloud Agent delegation can be disabled. Public template sharing can be locked in. Privacy Mode (Legacy) blocks Grok Bot entirely — the product requires cloud storage.

Stop-line. Do not put company data on a public Bot template. Do not use Privacy Mode (Legacy) and expect Bots to run. Do not assume Auto Review is a substitute for an empty description.

Generic drill

15 minutes. Write a one-page isolation decision for your SMB: which logins may live on the Bot computer, which require a second user or must never be saved. Three columns: system / on-computer? / why.

Personal build — Blue SteelCo wall

Default for this shop: one user for research + drafts (FireGuard, Cite, Reviewer, later Rack). Wix / IONOS / billing stay off that computer. If you later want a Bot to click around the CMS, that is a different Cursor user with no outbound email plugin. Write the wall into every Bot description: “No Wix admin. No registrar. No ads wallet.”

Done when the three-column table exists in /workspace/bluesteelco/sources/isolation.md.
