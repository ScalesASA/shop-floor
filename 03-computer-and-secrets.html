Explainer

Computer and secrets

Work runs on a persistent cloud computer with a browser, filesystem, and terminal. Closing your laptop does not stop a turn or a routine. Durable project files belong in /workspace.

TL;DR

You take over for passwords, passkeys, 2FA, CAPTCHAs, and payments. The Bot does not see the password. The signed-in session then persists — for every Bot on the account. Never paste keys into chat or ordinary files.

Step 1 — Watch, then take over

Open Agent Computer from the conversation. Complete only the blocked step. Tell the Bot to continue. If a site re-verifies, the Bot should pause and notify you rather than invent a bypass.

Step 2 — Shared state is the point and the risk

Handoffs work because files and logins are shared. That also means a drafting Bot can open a tab you signed in for a publishing Bot. Sign out of admin surfaces when the shift is over. Delete sensitive temp files when the job ends.

Step 3 — Recover before reset
  1. Retry / reopen the conversation
  2. Restart the app, check for update
  3. Recover Agent Computer
  4. Update Agent Computer (rebuild image, keep durable files)
  5. Reset only as last resort

Conversations live outside the computer. They survive a reset. Unsynced files do not.

Stop-line. No API keys, CMS passwords, or OTP codes in chat. Use the masked secret field when the product offers it. Do not store customer data in a public Bot template.

Generic drill

15 minutes. Sign the computer into a low-risk reader account (or a throwaway) on any SaaS you use. Confirm the Bot can see the logged-in page. Sign out. Confirm the next Bot cannot act as that user. Write the result in /workspace/smb-lab/computer-notes.md.

Personal build — Blue SteelCo computer hygiene

Create /workspace/bluesteelco/ with three folders: briefs/, drafts/, sources/. Put nothing from Wix admin here. If you must view the live site, use the public URL. Leave a one-line README in the folder: “Drafts only. Publish is human.”

Done when /workspace has a home for Blue SteelCo artifacts and Wix admin is not a saved session.
