# Shop Floor — Grok Bot course

Static HTML course for running Grok Bot on an SMB. Teaching is generic. The worked shop is Blue SteelCo (bluesteelco.com).

## Doctrine

- Never send, publish, or change production from a Bot.
- Never paste secrets into chat.
- Bots share one computer. They are not a credential boundary.

## Run locally

Open `index.html` in a browser. No build step.

## GitHub Pages

Put this folder at the repo root (or `/docs`) and enable Pages on `index.html`.

| File | Layer |
